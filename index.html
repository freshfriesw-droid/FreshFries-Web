🩺 تشخيص النسخة والأخطاء التقنية

للمدير العام في بيئة التجارب. يعرض توافق إصدار الواجهة مع قاعدة البيانات وعدد إخفاقات الدوال والأخطاء التقنية خلال آخر سبعة أيام. لا يخزن نص الخطأ أو محتوى الطلبات أو أرقام العملاء أو كلمات المرور. الفحص ليس شهادة أمان أو اعتمادًا للإطلاق.

جاهز لتسجيل الدخول.

📋 مركز التجربة الشاملة

مخصص للمدير العام على قاعدة التطوير فقط. جهزنا سيناريوهات كل أقسام Fresh Fries في جولة واحدة؛ نسجل نتيجة كل سيناريو عندما نبدأ التجربة النهائية، ولا نحتاج إلى تجربتها الآن. لا تسجل أرقام العملاء أو كلمات المرور في الملاحظات.

ابدأ بإنشاء جولة أو اختيار جولة محفوظة عندما يحين موعد التجربة الشاملة.
آخر تعديلات نتائج الجولة

إكمال جميع السيناريوهات لا يعني اعتماد الأمان أو الإطلاق تلقائيًا. يجب مراجعة تقارير RLS وصلاحيات API واستعادة النسخ الاحتياطية على بيئة مستقلة قبل أي تشغيل فعلي.

🧪 جاهزية النظام للتجربة الشاملة

للمدير العام فقط. يفحص هذا القسم وجود الجداول وتفعيل RLS وحالة إتاحة دالة التصفير وبعض مؤشرات الحماية النصية للدوال الحساسة، ويرصد تغييرات الأدوار التي أعادت الصلاحيات إلى الافتراضي. الفحص لا يثبت أمان النظام ولا يغني عن تجارب حسابات الموظفين.

اضغط «فحص جاهزية النسخة» لقراءة حالة قاعدة البيانات.

🔎 تدقيق سلامة البيانات

فحص للمدير العام فقط. يقرأ سجلات الطلبات المسلّمة والموصلين والإضافات والتسويات دون تغييرها. النتائج مؤشرات للمتابعة وليست إثباتًا بوجود مخالفة، أو شهادة أمان أو جردًا محاسبيًا. قد يكون فرق النقد موثقًا بصورة صحيحة.

حدد الفترة واضغط بدء الفحص (حتى 90 يومًا).

الملاحظات المصنفة

🛡️ أمان النظام — فحص قاعدة البيانات

👥 إدارة الموظفين والحسابات
