# STEP03 — استكمال المحرر البصري الشامل (مفتوح)
مرجع: وثيقة 24 نوفمبر 2026 §§6.2،6.3،6.7 وDEC-03، وخطة 25 نوفمبر. STEP02 مغلق، لا إعادة تنفيذ.
- توسعة سجل العناصر إلى حقول ومناطق وتبويبات في الشاشات القائمة، ضمن مفاتيح ثابتة، مع ضبط اللون فقط لأزرار آمنة محددة. ترتيب الحقول والمناطق الموسومة styleOnly ثابت.
- معاينة اصطناعية لاختيار عنصر، وقائمة خصائص محددة، ومصدر لكل قيمة موروثة حسب درجة الخصوصية.
- حالة DEC-03/QA-06–09: دليل تنفيذ جزئي؛ يتبقى إثبات الاختبار والنشر والتكامل، مراجعة تغطية العناصر وخصائص الشعار والمكونات الخاصة. لا إعلان إغلاق ولا انتقال للخطوة 04.
