# STEP06 — استوديو المحتوى والمتغيرات (قيد التنفيذ)
- نقطة الاستئناف: STEP05 مغلقة، a4d579a6b2e1f100c24922be1bc0dc522eb9c26a. DEC-09، §6.5، QA-38/41، TR-29.
- Supabase: 125 مفتاحًا و0 إصدارات قبل التعديل، 102/102 RLS.
- سجل أولي لـ318 مفتاحًا جديدًا من معرفات A07 ومصادر العرض. النصوص الحساسة تظل ظاهرة. إصلاح قبول المحارف الخفية والترميزات وحراسة تأكيد حفظ/نشر.
- المتبقي: تطبيق الترحيل بعد التحقق، إثبات ربط العرض، استكمال النصوص الديناميكية والعامة والتقارير والقوالب، اختبار التحرير والاستعادة وحماية المتغيرات، CI، الدمج والنشر. لا إغلاق قبل استيفاء الشروط.

- دفعة ثانية: 110 مفتاحًا للأزرار الديناميكية بنطاق واجهات ثابت، وصفحات الدخول والعميل العامة ضمن نطاق all دون فرع، وعناوين أقسام التقارير وإشعاراتها، مع حماية النصوص الحساسة. لا بيانات موظف أو عميل من RPC العام، ولا مسودة أو إصدار فرعي. إجمالي المرشحات 428, إجمالي السجل المتوقع 553. فحص الترحيل الأول ROLLBACK: 443 مفتاحًا، 3 قبولًا و12 رفضًا؛ لم يُطبق بعد. اختبارات الربط الشامل ما زالت مطلوبة.

- اختبار قاعدة البيانات الموسع: 44 تحققًا ناجحًا مع ROLLBACK؛ لم تُطبق الهجرة. اختبار المتصفح الأول: دورة المدير والرفض والاستعادة والعرض العام وسبعة مقاسات نجحت؛ فشل محدد cashier.guidance لمطابقته بطاقتين. قُيّد المحدد ببطاقة cashierOrders. أضيفت 88 مفاتيح من الحقول والعناصر المؤكدة في المصادر، بما فيها حقول الانضمام والموظف والتعويضات والتقارير التاريخية. إجمالي 641؛ إعادة التحقق مطلوبة.
